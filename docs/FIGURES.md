# Published figure sources

All figure assets in this documentation come from LaFINet: Laplacian-Based Frequency Injection Network for Camouflage Object Detection (Student Abstract), AAAI 2026, 40(48), 41107–41109.

- Article: https://ojs.aaai.org/index.php/AAAI/article/view/42179
- PDF: https://ojs.aaai.org/index.php/AAAI/article/download/42179/46140
- DOI: https://doi.org/10.1609/aaai.v40i48.42179
- Extraction: Poppler `pdfimages -all paper.pdf figure`.

`lafinet-architecture.png` is the native embedded Figure 1 image (4787 × 1376), from PDF page 2. The 16 images in `qualitative/` are the four rows and four columns of Figure 2, also from PDF page 2. Their names use the paper's original row order, without inferring dataset IDs or species. Each is 256 × 256. Prediction images retain the embedded JPEG encoding; other columns are extracted PNGs. No thresholding, contrast adjustment, or new model inference was performed. SHA-256 checksums are recorded in `qualitative/provenance.json`.
